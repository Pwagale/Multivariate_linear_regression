Multivariate Linear Regression Prediction App

This project is a Machine Learning web application developed using Python and Flask. The application uses a trained Multivariate Linear Regression model to make predictions based on multiple input features.

Technologies Used:
- Python
- Flask
- NumPy
- Pandas
- Scikit-learn
- Pickle
- HTML

Features:
- Accepts multiple input features
- Predicts the output using Multivariate Linear Regression
- Simple and user-friendly web interface
- Machine Learning model integration with Flask
- Easy to run and use
